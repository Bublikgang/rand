# Random Quote Generator

Автор: Сабаев Святослав

## Описание
Это GUI-приложение на Python, которое генерирует случайные цитаты из предопределенного списка, сохраняет историю, позволяет фильтровать цитаты по автору и теме, а также добавлять новые цитаты.

## Использование
- Нажмите кнопку «Сгенерировать цитату» для получения случайной цитаты.
- Введите имя автора или тему и нажмите «Применить фильтр» для фильтрации цитат.
- Нажмите «Сбросить фильтр» для сброса фильтров.
- В меню «Файл» → «Добавить цитату» для добавления новых цитат.
- История отображается в нижней части окна.

## Тестовые сценарии
- Генерировать цитаты несколько раз.
- Применять фильтры.
- Добавлять новые цитаты.
- Проверять сохранение истории между запусками.
